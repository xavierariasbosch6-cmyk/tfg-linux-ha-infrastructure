# \# TFG Linux HA Infrastructure

# 

# \## Descripción

# 

# Proyecto de Trabajo de Fin de Grado centrado en el diseño e implementación de una infraestructura Linux orientada a entornos DevOps/SRE.

# 

# La infraestructura incluye:

# 

# \- Múltiples nodos Linux Ubuntu Server

# \- Balanceo de carga con HAProxy

# \- Servidores web con Nginx

# \- Red interna con IPs fijas

# \- Automatización mediante scripts

# \- Contenerización con Docker

# \- Monitorización con Prometheus y Grafana

# 

# \## Arquitectura actual

# 

# \- Node1 → 192.168.19.128

# \- Node2 → 192.168.19.129

# \- Load Balancer → 192.168.19.130

# 

# \## Tecnologías utilizadas

# 

# \- Ubuntu Server

# \- VMware Workstation

# \- Nginx

# \- HAProxy

# \- Docker

# \- Prometheus

# \- Grafana

# \- Bash scripting
